# Archived browser-wide fixtures

These are the pre-cutover fixtures retained as source references for the former
multi-document/frame product scope. They are not active single-document smoke tests.
History routing, messaging, callback delivery, DOM named properties, module ownership
and native GC diagnostics require replacement coverage in the active suite. Moving a
fixture here does not establish that its former semantics or overall retention pass.
The original relative dependencies remain in the parent smoke directory; these files
are archival source, not a separately runnable test suite.
